ИИ чат және сұрақтар

Мұнда сіз PDD, жол белгілері, маневр жасау ережелері, нақты өмірлік жағдайлар туралы кез келген сұрақ қоя аласыз. ИИ жауап беруге тырысады.

Жаңа сұрақ қою

Бұл сұрақтар тек сіздің құрылғыңызда сақталады, кейін қарап шығуға ыңғайлы болу үшін.

Менің сұрақтарым

ИИ чат (AI ассистент)

Кез келген сұрығыңызды осында жазыңыз. Жауап бірнеше секундта келеді.

Назар аударыңыз: ИИ-ға сұрақ жіберу үшін артқы жағында (backend) арнайы API баптау қажет. Оны төменде түсіндіріп өтемін.

ИИ API кілтін қауіпсіз пайдалану

Сіз берген API кілтті тікелей HTML/JavaScript файлының ішіне жазуға болмайды – оны кез келген адам көреді. Сол себепті кілтті тек сервер жағында (backend) `.env` сияқты қорғалған файлда сақтау керек.

Төменде Node.js (Express) көмегімен өте қарапайым сервер мысалын қосып беремін. Сіз соны `server.js` ретінде сақтап, API кілтіңізді қорғалған түрде пайдалана аласыз.

Аккаунтқа кіру

Жаңа аккаунт тіркеу

Аккаунт деректері тек осы құрылғыдағы браузердің жергілікті жадысында сақталады (localStorage). Бұл оқу-демо нұсқасы.
